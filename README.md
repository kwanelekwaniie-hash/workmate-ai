# Workmate AI

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant with a clean light-grey, white, and dark-charcoal design, professional typography, cards, and sidebar navigation.

Include 3 features:

Smart Email Generator: Generate professional emails from user prompts, supporting Formal and Friendly tones. Allow editing and copying outputs.

AI Research Assistant: Summarize user-provided articles or topics, extract key insights, and present clear, structured results.

AI Chatbot: An interactive workplace assistant that responds intelligently and contextually to user prompts.

Use React and Tailwind CSS with a dashboard layout, responsive mobile navigation, structured prompts, editable AI outputs, loading states, and error handling.

AI functionality: Use Lovable’s available AI integration if supported. No custom backend, database, authentication, or external server. Do not use hardcoded generic responses; generate contextual answers from user inputs. If live AI requires additional setup, explain the limitation clearly.

Include a responsible AI disclaimer reminding users to verify facts and avoid sharing confidential information. Keep the UI polished, accessible, and easy to use. Prioritize all three core features and minimize unnecessary complexity.
